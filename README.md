# Baid & Co

Chartered Accountancy firm website built with Next.js, Mantine, SCSS, and Framer Motion.

## Pages

- `/` — Home
- `/about` — About the firm
- `/services` — Services overview
- `/services/[slug]` — Individual service pages
- `/contact` — Contact form

## Getting started

```bash
pnpm install
pnpm dev
```

Light / dark mode is available via the header toggle. Color theme variants have been removed.
